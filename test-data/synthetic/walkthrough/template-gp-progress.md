# Progress update for the GP

## Purpose

Write a short update to the patient's GP covering the selected reviewed notes, in date order.

## Source rules

- Use **only** the supplied reviewed notes.
- Preserve every request placeholder exactly; never guess an identity.
- Do not invent facts, diagnoses, risk findings, medication details or actions.
- State that information is not recorded when it is missing.
- Distinguish what the patient reported from what was observed.

## Document structure

- **Reason for writing**
- **Background from the first assessment**
- **Progress since**
- **Plan**

## Style

Professional British English, warm but concise, no longer than one page. Do not add a signature, clinician details or contact information; these are added locally.
