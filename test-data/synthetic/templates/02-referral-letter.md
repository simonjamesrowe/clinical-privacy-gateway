# Referral letter

## Purpose

Draft a request for an opinion; do not invent a referral urgency or specialist diagnosis.

## Source rules

- Use **only** the supplied reviewed notes.
- Preserve every request placeholder exactly; never guess an identity.
- Do not invent facts, diagnoses, risk findings, medication details or actions.
- State that information is not recorded when it is missing.
- Distinguish reported information from recorded observations.

## Document structure

- **Reason for referral**
- **Documented presentation**
- **Steps already taken**
- **Questions for the receiving clinician**

## Style

Use professional British English, short paragraphs and clear headings. Do not add a signature, clinician details or contact information; these are handled locally.
